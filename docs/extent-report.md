# Interactive HTML Report

At the end of a run, AgenTeX can produce a standalone **`extent-report.html`** — a self-contained,
dark-themed dashboard that opens in any browser with no server or network access.

## What's in it

- A donut chart of the run's pass/fail/blocked distribution.
- Per-status stat cards.
- Expandable per-test-case cards with step-by-step detail.

The file is fully self-contained (inlined CSS/JS), so you can email it or attach it to a ticket.

## How it works

The `extent-report` skill runs at the end of any run — one test case or a full parallel/sequential
batch — once final results are known, and writes `extent-report.html` next to `report.md`. The
browser-testing REPORT/MERGE steps mention it as an optional artifact.

Generated by the deterministic script:

```bash
node skills/extent-report/scripts/make_html_report.js
```
