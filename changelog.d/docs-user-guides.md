### Added

- **User Guide, in markdown and PDF:** two step-by-step guides under `docs/user-guide/`, each in its own folder with its PDF export: the AgenTeX User Guide in `agentex/` (20 chapters, a glossary and a cheat sheet, one markdown file each) and the short Mobile Testing User Guide in `mobile/`. Because the guides are markdown, anyone can update them and every page is searchable; `docs/user-guide/README.md` explains how to update them and re-export the PDFs. `docs/README.md` gains a "Find it fast — I want to…" task table and the UI Check page it was missing. The main README gains a Documentation section with the guides, a task table and a repository layout table. `skills/`, `scripts/`, `hosts/`, `templates/` and `references/` each get a README explaining their contents; `commands/`, `agents/` and `changelog.d/` are explained in the main README instead, because every `.md` file there is loaded as a command or agent or merged into the changelog. A new `llms.txt` at the repo root gives AI tools a one-file map of every page. Every docs page is now linked into one structure: `docs/README.md` has a docs map; each reference page starts with a breadcrumb to its guide chapter and related pages and ends with a "See also" footer linking the source; and about 60 Mermaid diagrams and charts (flows, sequence diagrams, state diagrams, bar and line charts of login time and estimation hours) explain each flow. `docs/contributing/writing-user-docs.md` documents these conventions. The release gate treats all of these as docs.
