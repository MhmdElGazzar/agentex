# Define an AgenTeX flow under GitHub Copilot

1. Resolve this skill's absolute path and take `../..` as the adapter/package root. Run `node <root>/scripts/resolve_runtime.js`; use its verified `coreRoot`. Work from the consumer project root.
2. Read `<coreRoot>/skills/define-flow/SKILL.md` in full and follow it as written — it owns the whole guided session: SETUP (target/environment resolution per test-execution; one unique `define-<HHMMSS>-<4hex>` Playwright session, never `default`), the STEP LOOP (propose → execute immediately → the user asserts the real outcome → append the confirmed step to the incremental draft), ASSEMBLE (propose `test/<suite>/<slug>.md`, save only on the user's confirmation), and the offered VALIDATE run. Read `<coreRoot>/skills/browser-driver/references/tools/playwright-cli.md` before the first browser action.
3. Real cross-turn continuity: this session spans many conversational turns and the user approves every step. Stop and wait for a real user response at each gate — step proposal/confirmation, the ASSEMBLE save approval, and the offered validation. Never advance a gate without the user's answer. After each user reply, re-verify the original session is still alive, the URL is unchanged, and the page-state hash matches the last observation before acting; if the lease expired or the page changed, do NOT click and do NOT silently reopen — say the state is lost and ask. On Windows, a resumed turn may falsely report `Browser '<session>' is not open` while the daemon is alive: check status/snapshot under narrow approval before declaring the browser lost.
4. Save the confirmed spec through the shared guard only: `node <coreRoot>/skills/define-flow/scripts/save_spec.js --draft <draft-relative-path> --output <test/path.md>`. It validates structure and creates exclusively; never overwrite or bypass it. Then close only your own session (`-s=<session> close`), verify the lease is gone, and clean the transient `.playwright-cli/` scratch. Only then offer the fresh validation run via the test skill.
5. Never modify application source, never print secrets, never record literal session values in the spec (record them symbolically with the concrete value as an inline example). Integration steps run only through the project's integration catalog, never improvised.
